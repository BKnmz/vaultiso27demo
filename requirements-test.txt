# Minimal dependency set for CI / the daily DevSecOps loop.
#
# Enough to run `python -m pytest tests/` and parse config.yaml — nothing more.
# The full desktop app (Streamlit UI, PDF ingest, GitHub sync) still needs
# requirements.txt.
#
# Deliberately NO --extra-index-url. requirements.txt pins torch==2.4.1+cpu from
# download.pytorch.org, which sandboxed and CI networks commonly block, and the
# "+cpu" local version has no fallback on PyPI so the whole install dies on it.
# Plain torch==2.4.1 resolves from PyPI and is all sentence-transformers needs.
#
# Test suite imports streamlit via ui/core.py (module scope) and pydantic_ai
# via critic.py (module scope), so both must be included here. Only the
# "openai" extra of pydantic-ai-slim is needed (critic.py/ui/core.py only
# use pydantic_ai.models.openai / pydantic_ai.providers.openai to talk to
# the local Ollama OpenAI-compatible endpoint) -- the umbrella "pydantic_ai"
# package pulls in the full extras set (anthropic, google, mcp, logfire,
# evals, cli, web), which drags in cloud-provider SDKs this project does not
# want and which is what caused the pyyaml resolution conflict below. Pinned
# to match requirements.txt's pydantic-ai-slim[openai]==2.9.0.
