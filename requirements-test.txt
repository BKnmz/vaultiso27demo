# Minimal dependency set for CI / the daily DevSecOps loop.
#
# Enough to run `python -m pytest tests/` and parse config.yaml — nothing more.
# The full desktop app (Streamlit UI, PDF ingest, GitHub sync) still needs
# requirements.txt.
#
# Deliberately NO --extra-index-url. requirements.txt pins torch==2.4.1+cpu from
# download.pytorch.org, which sandboxed and CI networks commonly block, and the
# "+cpu" local version has no fallback on PyPI so the whole install dies on it.
# Plain torch==2.4.1 resolves from PyPI and is all sentence-transformers needs.
#
# Excluded vs requirements.txt: pandas, pypdf, PyGithub — imported only under ui/,
# which the test suite never touches. Streamlit and pydantic-ai-slim are included
# because tests/test_get_review_verdict.py, tests/test_org_extraction.py,
# tests/test_org_profile_schema.py import ui/core.py (which does `import streamlit`
# at module scope), and tests/test_critic.py imports critic.py which imports
# pydantic-ai at module scope.
